# Sneak Peek for Windows, Mac and Linux

Download the newest version from [trysneakpeek.com](https://trysneakpeek.com), or from the
[latest release](https://github.com/michael-jordan-coder/sneak-peek-multiplatform-releases/releases/latest).

This repo holds the installers and the build that makes them. The app's code is private.

## The Claude Code plugin

`plugin/` holds Sneak Peek's plugin for Claude Code, which connects your own Claude Code
sessions to the app's canvas. It appears here with the first release that includes it, and is
updated from each published release. Install it in Claude Code with:

```
/plugin install sneak-peek --marketplace michael-jordan-coder/sneak-peek-multiplatform-releases
```
